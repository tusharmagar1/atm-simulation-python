# 🏧 ATM Simulation

A Python-based ATM Simulation built using Object-Oriented Programming and SQLite.

## Features

- PIN Authentication
- Check Balance
- Deposit Money
- Withdraw Money
- Change PIN
- Transaction History
- SQLite Database
- Persistent Account Data
- Input Validation

## Technologies

- Python
- OOP
- SQLite
- sqlite3

## Run the Project

```bash
python main.py
```
